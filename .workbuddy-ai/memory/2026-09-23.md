### ★★ 驱动 UI 的三个坑（都踩过，已写进 TOOLBOX）

1. **消息发不出去**：`setter + 派发 input 事件 + 点发送按钮` 会被 React 重渲染吃掉
   ⇒ 改用 **点输入框聚焦 → `Input.insertText` 真实键入 → 回车**，并用「输入框是否被清空」自检。
2. **必须先把页开出来**：桌面端 `launch()` 要求 `effectiveWcId` 是数字（`App.tsx:2198`），
   没绑定页 ⇒ 服务端循环建好了但**永远不被驱动**（`llmCalls=0`）。
   开页后界面切到浏览器视图、**聊天输入框不在 DOM 里** ⇒ 要再点「切回对话」。
3. **★★★ `clickText` 不能取「最后一个」匹配元素**：AI 的回复正文里含「过程可以在「内部频道」里看」，
   取最后一个就点到了**聊天气泡**上 ⇒ 顶栏 tab 4 次重试全 OK 但面板就是不出现。
   ⇒ 改成**取文本最短**的匹配元素（= 那个 tab）。
