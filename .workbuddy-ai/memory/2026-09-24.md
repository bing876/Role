2. `git merge-base --is-ancestor <branch> main` —— 是祖先才能零损失删
3. ★ `git diff --diff-filter=D --name-only -z <branch> main` —— **列出只在该分支存在的文件**
   （`-z` + `tr '\0' '\n'` 才能正确处理中文路径；用 `[ -f ]` 判断时也要注意 git 会输出八进制转义，
   直接拼进 `[ -f ]` 会假阴性 —— 以 `--diff-filter=D` 的输出为准）
