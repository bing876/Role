## 一、★★★ 根因（用户报的「页已创建、已加载，但没显示」）
第四列可见性 = `col.colOpen && browser.view === 'fullscreen'`（两个 state 的**与**）。
`browser.openUrl()` 里显式 `setView('fullscreen')`，但**没人告诉外壳的列** —— 只有三个触发点
（会话链接 / 🌐 启用 / 欢迎卡）顺手调了 `col.openColumn()`；**聊天里说「打开 XX」这条主路径漏了**
（`features/chat/useChat.ts` 的 `if (openUrl) { await browser.openUrl(...) }`）。
⇒ 层落进 `--hidden`（`transform: translateX(calc(100% + 16px))` 移出视野，实测 x=1180 > innerWidth=1164）。
**修法**：App 里一条 effect —— `browser.view === 'fullscreen'` ⇒ `col.openColumn()`（任何入口都兜住）。

## 二、★★ 顺线自查出的另两条真缺陷（同批修掉）
1. **StrictMode 假卸载销毁所有原生视图**（`BrowserPanel`）：`panelUnmountedRef` 是一次性布尔标志，
   cleanup 只设 true **从不设回 false**；而 `main.tsx:72` 里 `<StrictMode>` 是开着的 ⇒ React 在**同一实例**上
   跑 `setup → cleanup → setup` ⇒ 标志从挂载起**永远 true** ⇒ 宿主效果**每一次依赖变化**都销毁重建所有视图
   ⇒ 真机症状「**指定的内嵌页已经不在了（webContents NNNN 已关闭）**」、AI 只能重开一遍页。
   **修法**：不用跨渲染标志，改**代次 + 微任务**（`mountGenerationRef` + `queueMicrotask` 判断「有没有更晚的挂载」）；
   宿主效果里**故意不留 cleanup**。
   ★ 教训：**`useRef(初值)` 只在「新实例」上生效** —— 在 StrictMode 下它救不了「cleanup 设的粘性标志」。
2. **create 回执晚于关页 ⇒ 孤儿原生视图**（`useBrowserWorkspace.hostMounted`）：create 是异步 IPC，
