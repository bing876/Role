## 二、★★ 本机沙箱的两个新事实（实测）
1. **同步 spawn 一律被拦成 EBUSY**：`spawnSync(node)`、`execFileSync(node)` 都 EBUSY，

   ⇒ 验收脚本里起子进程一律用**异步 spawn + Promise**。

   `spawn('npx')` ENOENT、`execFileSync('npx')` EBUSY、Python `subprocess.run(['npx',…])` FileNotFoundError。
   统一改「`process.execPath` / `shutil.which('node')` + `node_modules/tsx/dist/cli.mjs`」。

## 一、★★★ Electron 二进制：GitHub 下载源不通，必须走镜像
- 现象：`npm install` **exit 0**、`node_modules/electron/package.json` = 44.4.5，
  但 **`dist/` 根本不存在**（postinstall 静默没跑成）⇒ 应用起不来。
- 手动 `node node_modules/electron/install.js` → `TypeError: fetch failed`。
- 实测连通性：`https://github.com/electron/electron/releases/...` → **HTTP 000（不通）**；
  `https://npmmirror.com/mirrors/electron/44.4.5/SHASUMS256.txt` → **HTTP 200**。
- 解法（**这是真下载，不是跳过变量**）：
  ```bash
  ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/" node node_modules/electron/install.js
  ```
  装完核对：`cat node_modules/electron/dist/version` → `44.4.5`；`electron.exe` 246MB。
- ★ 教训：**`npm install` 成功 ≠ Electron 二进制就位**。装完必须查 `dist/version`，
  别只看 `node_modules/electron/package.json` 的版本。
