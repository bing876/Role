## 二、★★ 本机沙箱的两个新事实（实测）
1. **同步 spawn 一律被拦成 EBUSY**：`spawnSync(node)`、`execFileSync(node)` 都 EBUSY，
   而**异步 `spawn` 正常**（`loop-kill9` / `r4` 一直是 `spawn`，所以它们没受影响）。
   ⇒ 验收脚本里起子进程一律用**异步 spawn + Promise**。
2. **`npx` / `npm` 在 PATH 上只有 `.cmd` / `.ps1`，没有 `.exe`** ⇒
   `spawn('npx')` ENOENT、`execFileSync('npx')` EBUSY、Python `subprocess.run(['npx',…])` FileNotFoundError。
   统一改「`process.execPath` / `shutil.which('node')` + `node_modules/tsx/dist/cli.mjs`」。
