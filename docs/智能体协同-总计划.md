# 智能体协同 · 总计划(对齐 GrokBot 无感)

> ★ 本文件是**跨会话的状态留痕**。会话意外死掉时,下一个会话读这一段就能接着干,不用重新摸。
> 每批做完必须更新「进度」段:已完成 / 未完成 / 已知缺口,写清到哪个 sha。

## 愿景

做一个像 GrokBot 的 AI 工作台:用户只管委派,界面越少让用户操心越好。判据:「这帮用户委派了,还是又多给他一件事管?」

## Grok 的取舍(对齐目标)

- 只留 Bots/Chats/Prompts/Tools/Artifacts 五个概念,其余藏起来
- 主对象是 Bot 不是对话;头像即状态(idle/thinking/working/waiting/blocked/done),不做六个指示器
- 砍掉仪表盘/指派板/手动交接;协同往来进对话流、折叠成一行摘要
- 用户自发造 Chief-of-Staff 做路由;Routines 定时/事件触发
- 描述=长期规矩,对话=这一次的活

## 架构地图

- `apps/server` 后端(Fastify+PG):`toolLoop.ts`(脑)、`routes/*`、`orchestrator/*`(委派/名单)、`memoryShared/memoryNormalize/memoryHygiene`(记忆)
- `apps/desktop` Electron:`driver.ts`(手)、`src/browser/*`(浏览器组件)、`App.tsx`(界面)
- `packages/shared` 类型与默认值
- 浏览器是单实例组件:`embedWcId` 单值、所有 tab 同舞台 z-index 分层、登录态按项目分区。换前端时这些是功能,不能碰

## 沙箱环境备忘(本会话实测)

- 没有 `node_modules`:`ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm install --no-audit --no-fund`
  (electron 二进制下载会被 TLS 挡,跳过后 554 包 6 秒装完)
- 没有 `psql` / `docker`,`apt-get` 出网被拦 → 真库用 `embedded-postgres@17.10.0-beta.17`
  (npm 上有真 PostgreSQL 17.10 二进制),装在**仓库外** `/home/user/pgverify/`,不污染 repo 的 package.json;
  `start-pg.mjs` 起在 `127.0.0.1:55432`,库名 `verifydb`
  ★ initdb 必须显式 `--encoding=UTF8`,默认 C locale 会给 SQL_ASCII,中文验收数据会出问题
- `VERIFY_DATABASE_URL=postgres://postgres:postgres@127.0.0.1:55432/verifydb`
