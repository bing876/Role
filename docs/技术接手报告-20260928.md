## 0. 三十秒版本

一个装在 Windows/macOS 上的 Electron 桌面软件。它不是聊天框——**它内置一个原生浏览器，AI 能像人一样打开网页、点按钮、读页面、填表单，把活真的干完**。用户说一句话「建个小美，专门盯店铺数据」，它当场变出一个专职智能体；多个智能体可以派活协作；所有数据（密钥、记忆、任务）都在用户本机，加密存储。

**技术上的真正亮点**：元素定位是「读懂页面再动手」（看按钮上写的什么字），不是猜坐标、不是死记网页代码。**这比主流的 vision+坐标 方案更抗网站改版。** 有 181 条自动断言钉着。

**当前的真相**：架构是仓库最值钱的资产（别重写）；但「代码 90% 完成」只覆盖了后端与引擎；**四个最关键的验证一个都没做**（真模型准确度 / 真打包 / 真机 / 真凭据）；界面层几乎没开始；有一个已知红的检查。

```
│     自造分区名）—— view-host.ts:70-80                         │
├─────────────────────────────────────────────────────────────┤
│ 主进程 apps/desktop/electron（Node）                          │
│  职责：浏览器宿主、CDP 遥控、桌面侧驾驶循环、服务守护、JWT 内存   │
│  drive(action) → driver.ts → debugger.sendCommand             │
├─────────────────────────────────────────────────────────────┤
│ 服务端 apps/server（Fastify，loopback 绑定）                    │
│  职责：路由、记忆、技能、编排、工具循环、模型唯一出口 llmFetch     │
└─────────────────────────────────────────────────────────────┘
```

### 一次「帮我在淘宝改标题」的完整链路

1. **用户输入** → `App.tsx` 输入栏 → `useChat.ts` → `POST /chat/stream`
2. **大管家路由** → `chiefOfStaff.ts`：先字面打分选智能体；置信度低于 `SEMANTIC_ROUTE_CONFIDENCE = 0.35` 才调 LLM；**12 秒超时 fail-closed 回字面结果**
3. **任务开始** → `POST /agent/loop/start` → 服务端建循环，状态 `running`
4. **桌面接手** → `agent.ts` 的 `runToolLoop` 轮询 `POST /agent/loop/next`（**超时 90 秒**）
5. **模型决策** → 服务端 `toolLoop.ts` 组提示词（含 `snapshotBrief` 页面摘要）→ `llmFetch`（唯一出口）→ 返回一个工具调用
6. **翻译成动作** → `toolExecutors.ts` 的 `resolveBrowserAction`（纯查表，**刻意与 shared 重复，`tool-registry-parity.mjs` 强制两边一致**）→ `BrowserAction`
7. **真的动手** → `driver.ts` `drive()`：`resolveTarget(wcId)`（**必须显式给，多页并存禁止自动挑**）→ `ensureAttached` 打 CDP 补丁（`CDP_TIMEOUT_MS = 8000`，**防死锁硬闸，别删**）→ 发 `Input.dispatchMouseEvent` / `DOM.*` / `Runtime.*`
8. **结果回来** → `agent.ts:263 toResult()` 转成 `LoopToolResult` → `POST /agent/loop/message` 回服务端
9. **循环**：服务端 `describeToolResult` 转人话喂模型 → 下一步。直到 `stop`（`reason` 必须 ∈ `{need_user, blocked}`）
10. **三个本地安全网**（`agent.ts`，不进模型）：
    - 连续 **2** 步失败（`FAILS_BEFORE_ASK`）→ 求助卡片
    - 连点 **3** 次页面无变化（`STALE_BEFORE_ASK`）→ 求助卡片
    - 要打字但找不到输入框、目标明显是搜索 → **直接跳搜索 URL**
    - 只有 `STUCK_ASK_REASONS` 白名单内的 reason 才弹卡片

### 委派（一个智能体派多个）

```
A 的循环 running
  └─ delegate 工具 → delegation.ts
       ├─ 登记 job（deadline = DELEGATE_TIMEOUT_MS，默认 10 分钟）
       ├─ A 的循环 park 成 waiting_job，浏览器交还用户
       └─ workers.ts 起一队：最多 5 个、并发 3 个
            ├─ 每人独立 AbortController + 超时（clamp 到 ≤60_000ms）+ 受整队 budgetMs 约束
            ├─ allSettled：单个失败不影响同队，逐条给回执
            └─ 结果按输入顺序返回（确定性）
```

**⚠️ 接手最关键的一条事实**：`subLoops.ts:14` 注释原话——「**子循环没有桌面手**，被 `/next` 找到反而是漏洞」。**派出去的工人默认不操作浏览器。** 这是刻意的安全决定，不是 bug。

## 6. 不能动的红线 ★接手第一天就要背下来

来源：`docs/工程纪律.md` + 各 ADR 失败模式表。

1. **旧 6 工具的名 / 顺序 / schema 冻结**。新增只能版本化追加（如 `click_semantic`）。
2. **接口只增不破**：新字段必须可选 `?`。禁止删字段、改名、收窄可空性、改语义。任何接口增删改必须**同一 commit 更新 `docs/前端接入契约.md`**。
3. **浏览器三条路径不许碰**：不卸载内嵌页 / 不 `display:none` / 不归零（`verify:shell` 有 golden 网）。
4. **本地优先**：数据不出本机；密钥装机随机生成（0600）；`llmFetch` 用 `redirect:'error'`。
5. **fail-closed**：定位不到就停下来问人，**绝不猜坐标、绝不 CSS 猜支付/密码字段**。
6. **不引 Tailwind / shadcn**（用户定案）。
7. **降噪定案不许推翻**。
8. **不许调断言调到绿**。改标准 = 改断言，必须在注释里写清被什么取代。
9. **新文件写完立刻 `git add`**（沙箱回合会重置）。
10. **禁止 `git clean -fd` / `reset --hard` / `checkout -- <file>`**；变异前先 `cp` 原件，还原后 `md5sum -c`。
11. **不做 PR、不切分支**（会话固定在 `arena/01a0e33c-role`）。
12. **`screenshot` 只进渲染层，绝不进服务端、绝不进提示词**（当前它是死能力，见 §8）。

| 洞 | 修法 |
|---|---|
| CORS 回显任意来源 | 白名单：`null`（安装包）/ `localhost:5173` / `127.0.0.1:5173`；无 Origin 头放行。**必须 `cb(null,false)` 静默拒绝**，传 Error 会变 500 |
