| B2 | `_probe-profile-fresh/` | 1 MB | 探针用的干净 profile |

**删了会失去什么**：上一次验收跑出来的浏览器缓存与本地存储快照。
里面**可能**包含验证码之类的调试痕迹 —— 从这个角度说，**删掉反而更好**。
