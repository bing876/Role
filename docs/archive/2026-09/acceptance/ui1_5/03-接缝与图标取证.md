| x | 98 | 99 | **100** | 101 | 102 | **103 ← 分界** | 104 | 105 | … |

### 1.5 与 C1 矛盾的对照（重要）

你此前提的 C1 是「分隔线自相矛盾：4 种机制并存」。渲染结果显示**4 种机制里有 3 种被抵消，最终不可见**：

| C1 提到的机制 | 声明值 | 实际渲染 |
|---|---|---|
| `.rail { border-right: 0 }` | 0px none | ✅ 无边框（确认） |
| `--col-rail-brd` 令牌 | 有定义 | ❌ 未被任何元素使用 → **死令牌** |
| `.sidebar { box-shadow: -1px 0 0 0 #2F2F30 }` | -1px 0 0 | ⚠️ **存在但看不出来**：颜色 `#2F2F30` 与列1 自身背景**完全相同** → 相当于「同色描边」，视觉零效果 |
| `.sidebar { border-right: 1px solid rgba(255,255,255,.05) }` | 1px 半透白 | ❌ 实测 `borderRight = 0px none`（被后续规则覆盖掉了） |

**所以要修正 C1 的表述**：不是「4 种机制叠加渲染出矛盾」，而是
**「1 个死令牌 + 1 个同色无效阴影 + 1 个被覆盖的边框 + 1 个显式 border-right:0」→ 最终是一条线都没有。**

> 那个 `box-shadow: -1px 0 0 0 #2F2F30` 的注释写的是「Round 194 补缝」，但它补的是**列1 自己左边缘**、用的又是**跟自己背景同色**的颜色 —— 所以它既没有「补」出可见线，也没有制造双线。**它是个空操作。**

## 任务 2 · 列0 顶部图标渲染（C3）

### 2.1 实测几何（三个图标 + 头像）

| 元素 | rect | 方块尺寸 | radius | 图标位图 `background-size` | 说明 |
|---|---|---|---|---|---|

- 三者水平位置一致：`left: 9.5px`（= (60−41)/2），**横向居中正确**。
- 纵向：`top` 分别 `14 / 72 / 116`，间距 `58 / 44`。**首段 58px 明显大于后段 44px** —— 但这是设计如此（头像与图标组之间留有分组间隔），不是错位。
- `::before` 高亮块：41×41、radius 10px、`background: rgba(255,255,255,.16)`、`z-index:-1`。**方块本体与高亮块同尺寸、同心 → 居中没问题。**

### 2.2 ★ C3 确认：图标相对方块偏小

| 图标 | 方块 | 位图 | 占比 | 视觉判断 |
|---|---|---|---|---|
| 消息 `.tab` | 41×41 | **34×34** | **82.9%** | 尚可，但四周留白仅 3.5px |
| 知识库 `.rail-kb` | 41×41 | **22×20** | **53.7% / 48.8%** | ❌ **明显偏小**，四周留白近 10px，视觉发空 |

- 位图**确实居中**（`background-position: 50% 50%`，实测生效）。
- 但**尺寸没跟着方块一起放大**：Round 198 把方块从 34px → 41px（+20.6%），而位图仍是 34px / 22×20。
- 消息图标 34px 位图里图形本身还有内边距，实际可见图形约 24–26px → **有效占比仅 ~60%**。
- 知识库图标 22×20 位图里图形更小，可见图形约 18×16px → **有效占比仅 ~42%**，在 41px 方块里显得**很小、很空**。

### 2.3 观察描述（基于看图，不是看 CSS）

**6 倍放大图 `T2f-rail-icons-3x.png` / `T2a-rail-icons-overview.png` 上肉眼可见：**

1. **头像「U」饱满** —— 渐变方块 41×41，字母 U 撑满约 60% 面积，视觉重心稳。
2. **消息气泡偏小且偏上** —— 白色气泡图形在 41px 灰块里约占中间 58%，上方留白略多于下方（气泡尾巴朝左下造成的不对称），整体**看起来比上面的头像小一圈**。
3. **知识库（文件夹）最明显偏小** —— 白描边文件夹只占 41px 方块的约 40–45%，四周一圈近 10px 的空白，**在三个元素里视觉权重最弱**，和上方头像、和下方设置三线都「不成比例」。
4. **设置三线（hamburger）最协调** —— 20px 宽、总高 14px，三线 2px + 间距 4px，在 60px 窄栏里宽度适中，视觉重量反而和头像更接近。
5. **三个图标的「可见图形直径」是递减的**：头像 ~26px > 消息 ~24px > 知识库 ~18px，**导致整条竖列节奏不齐、越往下越空**。
6. `::before` 的 41×41 高亮底块**尺寸正确、居中对齐**，没有问题 —— 问题**纯粹在内部位图偏小**。
