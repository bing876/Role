## 二、休眠的三层设计（这是核心，请重点拍板）

### 2.1 触发条件 —— 两层阈值，不是一刀切

```
   使用中 ──5 分钟没用──▶ 浅休眠 ──累计 30 分钟──▶ 深休眠
     ▲                      │                        │
     └──────── 一被点到 / 被驾驶 / 被唤醒 ◀──────────┘
```

| 状态 | 触发 | 干什么 | 省什么 |
| --- | --- | --- | --- |
| **活跃** | 默认 | 正常 | — |
| **浅休眠** | **5 分钟**没被用 | `<webview>` 保留（`opacity:0`），但**暂停页面里的 JS 定时器** + 降帧 | 省 **CPU**（视频还在后台播的典型场景就靠这挡） |
| **深休眠** | 浅休眠后再**累计 30 分钟** | **卸载** `<webview>`，只留快照 | 省 **内存**（这是"不占内存"的正解） |

**为什么不一上来就深休眠**：卸载再重载会有白屏 + 重新登录/重新加载的等待。
5 分钟就卸，用户切回来频繁看到白屏会很烦。**浅休眠是"便宜的先做"，深休眠是"贵的后做"。**

**硬约束（不做任何例外）：**
- **正在被驾驶的页（`drivingIds`）永不休眠** —— 不管它多久没被"用过"。
  AI 正在上面跑任务，收起来就等于把任务弄断了。这是**红线**。
- 当前**正在前台显示**的那张永不休眠。
- 只有**一个** tab 时**不深休眠**（卸载了用户回头就没东西看，体验很差）。

### 2.2 深休眠要存什么快照

卸载前抓一份：

```ts
interface TabSnapshot {
  url: string;           // 当前真实地址（不是 bootUrl —— 可能已经导航过）
  title: string;
  scrollY: number;       // 滚动位置
  formDrafts: Array<{ selector: string; value: string }>;  // 未提交的输入
}
```

唤醒时：重新 `<webview src={url}>` → `did-finish-load` 后 `window.scrollTo(0, scrollY)` → 回填表单。

> ⚠️ **诚实的边界**：快照**救不回**这些 ——
> 1. 页面里的**登录态**（cookie 是按 partition 存的，不会丢，所以这点其实没问题）；
> 2. **页面的运行时状态**（视频播到第 37 分钟、未提交的富文本编辑器、SPA 的内存态）；
> 3. **跨源 iframe 里的表单**（读不到）。
>
> 我会在休眠时的 tooltip 上老实写：「已休眠，唤醒后会重新加载页面」。

### 2.3 唤醒时机（请拍板）

| 选项 | 行为 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **A（我倾向）** | 切回那张 tab **自动唤醒** | 最顺手，符合 Chrome 直觉 | 会有一瞬间白屏 |
| B | 显示占位卡「已休眠 · 点一下恢复」 | 用户有掌控感，不浪费内存去唤醒他其实不想看的页 | 多一次点击 |
| C | 浅休眠自动醒、**深休眠**要点 | 折中 | 两套逻辑，行为不一致，用户会困惑 |

**我倾向 A**，理由：Chrome 就是自动唤醒的，用户预期如此；
而且**只有深休眠才有白屏**（5 分钟内的浅休眠是瞬间恢复的，无感）。

### 2.4 一个必须一起定的细节

**如果 AI 要给一张「已深休眠」的页派任务怎么办？**

（比如：某页睡了 40 分钟，用户突然说"去那个速卖通的页上看看价格"）

| 选项 | 行为 |
| --- | --- |
| **A（我倾向）** | **AI 先唤醒它（等加载完）再派任务**，并在日志里说一句"先把那张睡着的页叫醒" |
| B | 直接派，让 AI 自己面对"页是空的" |

**必须选 A** —— 选 B 等于给 AI 挖坑。

## 五、自动化测试会怎么测（提前说明，你验收时好对照）

1. **休眠触发**：伪造 `lastActiveAt` 倒退 6 分钟 → 断言那张页进入浅休眠；
2. **红线不可破**：把某页标进 `drivingIds` 再倒退 2 小时 → 断言它**依然清醒**；
3. **内存真的降了**：深休眠前后读 `app.getAppMetrics()` 的进程数/内存 → 断言**真的少了一个渲染进程**；
4. **快照能还原**：造一个有滚动位置 + 表单草稿的页 → 深休眠 → 唤醒 → 断言 `scrollY` 与草稿回来了；
5. **反证**：把休眠逻辑关掉 → 断言 1/3/4 全部变红。
