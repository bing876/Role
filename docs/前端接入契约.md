# 前端接入契约（以代码为准）

> **本文件是前端接入的唯一契约清单。** 桥方法 / HTTP 端点 / SSE 事件 / 共享类型，全部**以代码为准**：
> - 桥方法：`apps/desktop/electron/preload.ts`（实现）+ `packages/shared/src/index.ts` 的 `WorkbenchBridge`（类型）
> - HTTP 端点：`apps/server/src/routes/*.ts`（`app.get/post/...` 注册处）
> - SSE 事件：`apps/server/src/routes/chat.ts`（`sse()`）+ `apps/server/src/loopSse.ts`（`broadcastLoopEvent`）
> - 共享类型：`packages/shared/src/index.ts`（`@ai-workbench/shared`）
>
> **版本**：2026-09-27 起建。base commit `65f224c`（分支 `arena/01a0d0a8-role`）。

## ⚠️ 契约纪律：只增不破（append-only）

自本文件建立之日起，**接口只增不破**：

1. **可增**：新增桥方法、新增 HTTP 端点、新增 SSE 事件名、新增类型字段（可选字段 `?`）、新增枚举值。
2. **不可破**：
   - 不许**删除 / 改名 / 移动**任何已存在的桥方法、端点、事件名、类型字段。
   - 不许**收窄**已存在字段的可空性 / 类型（`string` → `number`、`T` → `T | null` 收紧）。
   - 不许**改语义**（同名同签名但行为变了）—— 要改语义就**新增**一个名字。
   - 不许**删枚举值**（`BrowserEvent`、`BrowserAction['action']`、`TaskPhase`、`CollabKind` 等）。
3. **要破时怎么办**：先在本文登记一条「废弃计划」（谁替代、何时删），并走用户拍板；过渡期新旧并存。
4. **改动时**：任何接口增删改，**同一 commit 里必须同步更新本文件**（清单是代码的镜像，不是事后补的）。

> 破坏性变更的定义以「前端只改代码、不改契约就能继续跑」为准：凡是前端不改就会红 / 跑错的改动，都算「破」。

## 2. 桥事件（主进程 → 渲染，`window.workbench.on(event, cb)`）

事件名类型 = `BrowserEvent`（`packages/shared/src/index.ts`）。回调参数 `payload?: string`（**JSON 字符串**，调用方自己 `JSON.parse`）。

| 事件 | 通道 | payload（JSON.parse 后） | 用途 |
|---|---|---|---|
| `open` | `workbench:browser:open` | — | 主进程指令：打开内嵌浏览器区域 |
| `show` | `workbench:browser:show` | — | 显示 |
| `hide` | `workbench:browser:hide` | — | 隐藏 |
| `focus` | `workbench:browser:focus` | — | 聚焦 |
| `state` | `workbench:browser:state` | `TaskState` | 第 4 步状态机广播（含 `pausedBy`/`wcId`） |
| `agent` | `workbench:browser:agent` | 步摘要/文档结论（可带 `wcId`） | 第 7 步主进程驾驶员循环的事件镜像（权威循环在主进程） |
| `settings` | `workbench:browser:settings` | `WorkbenchSettings` | 第 22 步配置变更广播 |
| `resources` | `workbench:browser:resources` | `ResourceAlert` | Phase 4 资源守护者广播 |
| `opentab` | `workbench:browser:opentab` | `OpenTabRequest` `{ url, agentId: number\|null, sourceWcId }` | 第 23 步：内嵌页里 in-page 的 `window.open`/`target=_blank` → 渲染层**新开一条 tab**（不串智能体） |

## 3. HTTP 端点

全部挂在本机服务端（默认 `http://127.0.0.1:8787`）。除 `GET /health`、`POST /auth/*`（登录前）外，其余都要 `Authorization: Bearer <token>`。
错误统一形状 `{ error: string }`（HTTP 4xx/5xx）。

### 3.11 片2 · MCP 通用桥（2026-09-27）

设置抽屉「能力与连接 → MCP 连接」填 Streamable HTTP 地址（公网仅 HTTPS，本机回环可 HTTP）+ 可选 Bearer token；加时 `initialize` 握手 + `tools/list` 拉工具，才保存。鉴权整份 JSON 走 `mcp_servers.auth_enc` AES-GCM 密文，读回仅布尔 `hasAuth`，不回 token；所有接口均需 Bearer 登录态并按 `user_id` 隔离。**不支持 stdio / shell 命令**。

|---|---|---|---|---|

## 4. SSE 事件

### 4.1 `POST /chat/stream`（渲染层直连）

`Content-Type: text/event-stream`。命名事件 + 无名（delta）事件。

| 事件名 | data（JSON） | 说明 |
|---|---|---|
| `meta` | `{ conversationId: number, userMessageId: number, agentId: number, mention?: MentionMeta }` | 本轮元信息（建会话/消息 id、哪个智能体在说话） |
| `loop` | `{ loopId: string, maxSteps: number, agentId: number, pageUrl: string, wcId: number }` | 本轮是页面任务，建好了服务端工具循环（**保持长连**，供主进程步骤广播） |
| `search` | `{ phase: 'start', query }` \| `{ phase: 'done', query, results, tookMs }` \| `{ phase: 'error', query, message }` | 联网搜索进度（done 带条数 tookMs；error 带 `message`） |
| `error` | `{ error: string }` | 出错（模型中断 / 入库失败等） |
| `done` | `{ conversationId: number, messageId: number, contentLength: number, searches: number, sources: Array<{...}> }` | 完成（messageId=入库的助手消息；sources=可点来源，空数组=没搜过） |
| *(无名)* | `{ delta: string }` | 增量文本（打字机） |

### 4.2 工具循环广播（`broadcastLoopEvent`，挂在 `/chat/stream` 的 loop 长连上）

循环跑动时服务端通过 `loopSse.ts` 的 `broadcastLoopEvent(loopId, event, data)` 往**同一条 SSE 连接**推结构化事件：

| 事件名 | data（JSON） | 说明 |
|---|---|---|
| `step` | `{ step: number, call: SafeCall, description: string }` 或 `{ step, phase: 'done', summary }` | 一步工具调用（或本轮收工 summary） |
| `note` | `{ level: 'info'\|'warn'\|'error', text: string }` | 步骤完成/未达成/补充指令等提示 |
| `ask` | `{ reason: string, question: string, step: number }` | AI 卡住求助（人工介入卡片） |
| `image` | `{ url: string, caption?: string }` | 能力与连接(2026-09-27)：生成图片（已落项目目录 + 写进对话流；url 形如 `/projects/<pid>/images/<file>`，前端前缀 `API_BASE()` 后当 `<img src>` 用） |
| `stopped` | `{ reason: string }` | 循环停下 |
| *(无名)* | `{ delta: string }` | 循环里 AI 的增量话术 |
| `done`（endLoopSse 终帧） | `{ conversationId: number, done: true }` / `{ stopped: true, reason? }` | 循环结束帧 + 关流 |
