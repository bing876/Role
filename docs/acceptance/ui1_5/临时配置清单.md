## 一、总原则

下列每一条，**原型文件里都没有对应设计**。它们是 Work Buddy 为了让 Electron 应用能跑起来、
能在本机（虚拟机/无 GPU 沙箱环境）启动、能满足用户「去掉标题栏 + 按 1400×900 铺满」的
口头要求，而**临时选定**的参数。请逐条确认：保留 / 改成别的值 / 删掉。

标记说明：
- 🔴 **高影响** —— 用户能直接看到或感知到，改起来影响面大
- 🟡 **中影响** —— 只在特定场景出现
- ⚪ **低影响** —— 技术细节，通常不用管

## 二、清单

### 1. 🔴 无边框窗口 + 自绘拖拽带

| 项 | 值 | 原型里的情况 |
|---|---|---|
| `frame: false` | 关掉 Windows 原生标题栏 | 原型是浏览器里的 HTML 模拟器，**没有系统标题栏这个概念**；但原型里画了 `.win-controls`（min/max/close 三个 11×11 SVG，见第 2874-2884 行） |
| `.wtDragStrip` | 顶部 **固定 32px** 透明条，`-webkit-app-region: drag`，`z-index: 9999` | **原型里没有拖拽带**。原型有个 `.top-area`（`height:30px`，第 1029-1032 行），但它是 `pointer-events:none` 的**空白占位**，注释写明「未来放功能插件」，**不是拖拽区** |
| `.wtApp { padding-top: 32px }` | 内容整体下移 32px 让出拖拽带 | 原型无 |

**我临时定的：**
- 拖拽带高度 **32px**（不是 30px，也不是原型的 `--top-area: 30px`）—— 取 32 是为了让鼠标容易点中
- 拖拽带做成 **`position: fixed` 透明覆盖层**，而不是复用原型的 `.top-area`
- **没有实现最小化 / 最大化 / 关闭按钮**（用户明确说「不需要顶部那个 win 的缩小放大那一栏」）。代价：关窗只能靠任务栏右键或 Alt+F4

**待确认：**
- 32px 这个数要保留吗？若要复用原型的 30px，我改一行常量即可
- 以后要不要做自绘 `.win-controls`？（原型里有现成的三个 SVG 可直接搬）

### 2. 🔴 窗口尺寸策略

| 项 | 值 | 原型里的情况 |
|---|---|---|
| `width: 1400` / `height: 900` | 开机即 1400×900 | ✅ **这一条有原型依据**：原型第 186 行 `--frame-w:1400px; --frame-h:900px` |
| `minWidth: 1400` / `minHeight: 900` | **窗口不能缩小** | prototype 没有最小尺寸概念（它是个 div） |
| `--wt-shell-min-w: 960px` | CSS 层最小宽度 960px | 原型无 |

**我临时定的：**
- 把 `minWidth/minHeight` **钉死在 1400×900** —— 这是我自己加的。副作用是**窗口完全不可缩小**；
  若用户显示器小于 1400×900，窗口会超出屏幕边界。
- `--wt-shell-min-w: 960px` 是**在无边框改造之前就存在**的旧值（`tokens.css:67`），
  现在窗口最小就是 1400，这个 960 已经**永远不会生效**，属于死值

**待确认（建议改）：**
- 是否把 `minWidth/minHeight` 放宽到 **1100×700**，让高 DPI 小屏用户也能用？
- 是否删掉/更新 `--wt-shell-min-w: 960px` 这个死值？

### 4. ⚪ 本机专属启动参数（不影响产品设计，仅记录）

| 项 | 值 | 原因 |
|---|---|---|
| `--no-sandbox` | 启动必须带 | 本机（虚拟机/容器）没有可用 GPU 沙箱。不带会 `FATAL:gpu_data_manager_impl_private.cc(423) GPU process isn't usable. Goodbye.` 然后崩溃退出（码 2147483651） |
| `backgroundColor: '#1a1a1a'` | 主进程窗口底色 | 这是**跟随桌面端现有暗色主题**挑的，不是原型值。原型整个 `.frame` 浮在桌面壁纸上，没有单一底色 |
| `autoHideMenuBar: true` | 隐藏 Electron 默认菜单 | 常规做法 |

**说明：** `--no-sandbox` **只在本机需要**。用户自己的正常桌面环境**不需要**加它，
也不应该硬编码进产品。这里记录是为了后人排查「为什么本机要以特殊参数启动」。
