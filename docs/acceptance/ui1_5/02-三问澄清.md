## 问题 2 · R201「卡片重设计」是什么

### 2.1 先纠正一个前提

R201（`<style id="r201-tweaks">`，A 文件 6879–6980 行，5 个小节）里跟「卡片」沾边的只有 **第 5 节**。R201 五节全貌：

| 节 | 内容 | 跟卡片有关？ |
|---|---|---|
| 1) | 列0 icon 左右居中（.tab/.rail-kb 由 34px 放大到 41px 后重新对齐） | 否 |
| 2) | 头像态隐藏「消息 / 知识库」icon（避免与 chip 列叠在一起） | 否 |
| 3) | 抽屉 icon：头像态下 `.menu-btn` 显示三条白线替代字母头像 | 否 |
| 4) | 列0「当前项目的智能体头像」容器（`.rail-agents`） | 否 |
| **5)** | **创建项目卡片：整体放大 + 纯黑不透明 + 「创建」按钮改白底黑字** | **是** |

**「卡片重设计」= 第 5 节 = 「创建项目」卡片（`.xyzcp-card`）的视觉重做。**

### 2.2 是否跟「浏览器任务」相关？—— 不相关

工作台里的「卡片」一共有 4 类，逐一核对：

| 卡片 | 选择器 | 状态 | 跟浏览器任务相关？ |

## 问题 3 · 「项目 chip」是什么

### 3.1 一句话定义

**「项目 chip」= 头像态下，列0（60px 竖栏）顶部的方形项目方块**。它就是 `.agent-chip`，但 **R197 之后它的语义从「智能体」改成了「项目」**。

关键源码注释（A 文件 6543–6554 行）：
```
Round 197：项目层（列0 = 项目 / 列1 = 项目下的智能体）
 · 点头像 → 列0 变成项目列表（项目A / 项目B / … ＋ 新建）
 · 单击项目 = 只移动选中框（不切换、不弹列1）
 · 双击项目 = 确认切换 → 列0 恢复常规、列1 显示该项目智能体
```

### 3.2 它与列0 / 列1 的关系

| 层 | 常规态（默认） | 头像态（点头像后） |
|---|---|---|
| **列0**（60px） | 字母头像「U」+ 消息 icon + 知识库 icon + 设置 hamburger | **顶部变 3 条白线（抽屉 icon）**，下方 = **项目 chip 列** + 末尾「＋」 |
| **列1**（270px） | 搜索栏 + 联系人列表 | 宽度收 0、隐藏 |
| 语义映射 | 列0 = 全局导航 | **列0 = 项目；列1 = 该项目下的智能体** |

同一个 `.agent-chip` 类名，两种语义：R197 之前 chip ↔ 智能体 1:1；R197 之后 **chip = 项目**（第 6635–6637 行注释明说「现在 chip 是**项目**」）。

### 3.4 交互（R197/R198/R199 全套）

| 动作 | 行为 |
|---|---|
| 单击 chip | **只移动选中框**（capture 阶段 `stopPropagation`，拦掉旧的自动切换） |
| 双击 chip | **确认切换项目** → 列0 回常规、列1 换该项目智能体 |
| 右键 chip | 弹 `#projCtxMenu`：**重命名 / 归档**（实测 132×78，两项） |

| chip 内首项 | 该项目「母鸡」智能体（`data-hen="1"`，带「母」角标，不可删） |

### 3.5 「列0 智能体头像与项目 chip 视觉完全相同」这句遗留项 —— 已核实

**这句是对的，而且是刻意的**（A 文件 6923–6925 行注释）：

> 智能体头像方块：视觉与 `.agent-chip` **完全一致**，但**刻意不复用 `.agent-chip` 类名** ——
> R197 在 document 捕获阶段把所有 `.agent-chip` 当项目块处理并 `stopPropagation()`，
> 带上那个类会让点击到不了本容器。

即：
- `.agent-chip` = **项目**方块（列0 项目列表态）
- `.rail-agent-tile` = **智能体**方块（列0 的 `.rail-agents` 容器里，拖列1到最左时出现）
- 两者 CSS **逐条相同**（41px / radius 10 / 17px / 同 `--c1` 底色算法），只是类名不同 → **视觉零差异**

`.rail-agents` 与 `.agent-list` 互斥（默认 `display:none`，`.frame.agent.rail-agents-mode` 才显示）。
