### 一处刻意未复刻（已在报告如实标注）

原型 A 的 `nav.rail` 带 `border-radius: 20px 0 0 20px`——那是原型「浮动 frame」
（1400×900 画布置于 1488×988 视口中、四周留白）的呈现方式。
本项目 React `.wtApp` 是**铺满整窗的壳**，若照抄这个圆角会把应用窗口左上/左下切掉。
故：**不照抄**，其余数值全部照抄。若后续希望 React 也做成浮动 frame，需要先改壳层排布，
属于本次范围外，未擅自动手。
