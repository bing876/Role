分支 `arena/01a09b16-work123` 现在指向 `284d45d`，父提交 `2b4f41f`，**工作区干净**。

提交前先把索引里的 842 个垃圾文件清掉了（构建产物 / Electron 调试 profile / 799 MB 备份），
并在 `.gitignore` 补了 4 条规则堵住源头：`apps/desktop/release-*/`、`_rollback-backup-*/`、
`.workbuddy-ai/udd-*/`、`scripts/verify/__pycache__/`。

> **本机坑**：`git commit` 对含 `/` 的分支 ref 会**静默失败** —— 打印了新 commit 号、
> 退出码 0，但 ref 文件不落盘，`git log` 报 "does not have any commits yet"。
> 两次提交都复现了。修法是从 `.git/logs/HEAD` 取回 40 位 sha，
> 再 `mkdir -p .git/refs/heads/arena && printf '%s\n' <sha> > .git/refs/heads/arena/01a09b16-work123`。
> **以后在这台机器上提交完，必须校验一下 `git log -1`。**
