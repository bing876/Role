# ref-guard 运行日志

**实时日志在 `.git/ref-guard.log`**（在 `.git/` 里，不进版本控制）。
本目录只放**带日期的快照**，供事后取证。

格式：`<时间>  <FIXED|FAILED|WARN>  <ref>  修复前=<值>  修复后=<值>`

| 类型 | 含义 |
| --- | --- |
| `FIXED` | 检测到 ref 丢失并**自动修复成功** |
| `FAILED` | 修复失败，需要人工介入（同时有 stderr 报警 + 退出码 1） |
| `WARN` | 历史体检异常（根提交数 > 1）—— **只报警，绝不自动改历史** |

> 本仓库分支名含 `/`（`arena/01a09b16-work123`），**每次提交都会丢 ref** ——
> 所以快照里出现连续的 `FIXED` 是**预期现象**，正说明防呆机制在工作。
>
> 快照**有意不实时同步**（否则每提交一次就过期一次，永远追不上）。要看最新状态直接读 `.git/ref-guard.log`。
