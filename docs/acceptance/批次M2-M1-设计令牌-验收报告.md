## 「零视觉改动」怎么证的(本沙箱无显示环境,走源码层 CSS 断言,与 M0 ⑦ 样式红线同口径)

设计 CSS 里**可能打中当前 DOM** 的规则只有三类,逐条钉死:

1. **99-theme 四条列规则**(都带 `!important`)→ 断言全部 scoped 在 `.frame ` 之下;当前 DOM 无 `.frame` 元素 → 打不中(旧 `aside.sidebar` 安全);
2. **02-base** → 断言只有 `body.viewport` 一个选择器(当前 body 无此类);
3. **01-tokens** → 断言无类选择器(只有 `:root`/`*`/元素族/`@font-face`),且 `*{box-sizing:border-box}` 与 styles.css 既有规则**同值** → 盒模型无变化;`--font-ui` 等新变量无人引用 → 字体无变化。

加上:导入顺序钉死(design 先、styles.css 后)、两文件与原版**逐字节一致**、99-theme 逆映射(剥说明+去 4 前缀)后与原版**逐字节一致**(多改一个字节都红)、字体同 sha256。
