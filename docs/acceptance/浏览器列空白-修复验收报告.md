## 一、症状与真机复现

**用户报**:发「打开抖音」→ 右侧浏览器面板空白;页已创建、已加载,但没显示。

**复现方式**(真机,dev 桌面端 + CDP 直插渲染层;`--remote-debugging-port=9222`):

1. 起 vite(5173)+ `electron .`(主进程真起 PG + 服务端);
2. 一键演示账号登录;
3. 在输入框里真打「打开抖音」并点发送(React 原生 setter + `input` 事件,完整鼠标序列点击);
4. 逐步读渲染层真相。

**复现结果(修前,逐字)**:

```
+1200ms {"layer":"browserLayer browserLayer--hidden","tabs":["douyin.com"],...}
guests: ["https://www.douyin.com/"]
```

- 标签页建了、guest 真加载了(`/json/list` 里能看到 `https://www.douyin.com/`)、AI 真开始驾驶它;
- 但 `.browserLayer` 是 **`browserLayer--hidden`** —— 第四列被
  `transform: translateX(calc(100% + 16px))` **整体移出视野**
  (实测 `getBoundingClientRect().x = 1180`,而窗口 `innerWidth = 1164`)。
- ⇒ **页已创建、已加载,却看不见** —— 与用户描述逐字一致。

**同因异路**(证明不是 useChat 一处漏):CDP 直调 `window.workbench.openBrowser('https://www.douyin.com')`
(走 `openFromMain` → `openUrl`)之后,层同样 `--hidden`。

## 三、三个修复(一条一 commit)

### 修 1 · 浏览器列可见性以 `browser.view` 为单一真相(ADR-0005)

- **根因**:第四列可见性 = `col.colOpen && browser.view === 'fullscreen'`(两个 state 的**与**)。
  `browser.openUrl()` 里**显式**写了 `setView('fullscreen')`(它自己的注释:「调用方都是『用户明确要看浏览器』」),
  但**没有任何人把这件事告诉外壳的列** —— 只有三个触发点(会话链接 / 「🌐 启用」/ 欢迎卡)顺手调了
  `col.openColumn()`;**聊天里说「打开 XX」这条主路径漏了**
  (`features/chat/useChat.ts` 的 `if (openUrl) { await browser.openUrl(...) }`)。
- **改法**:App 里加一条同步 effect —— `browser.view === 'fullscreen'` ⇒ `col.openColumn()`。
  任何让 view 变成 fullscreen 的路径(今天 4 条、将来更多)都自动把列打开。
  `browser/` 一行不动(分层规则:feature 不许反向依赖外壳)。
- **口径修正**:`app-shell-smoke` 里「'open' 事件 = 后台开页(层必须 `--hidden`)」这条断言的前提
  **与生产码矛盾**(`openFromMain` → `openUrl` → `setView('fullscreen')`),按「改标准 = 改断言」改成
  与代码实际语义一致的新口径(主进程 open = 要给人看 ⇒ 列可见)。
- **验收**:`verify:shell` 新增/改 2 条(④ / ⑧-4b),反证 C6 摘掉 effect → 两条**都变红**。

### 修 2 · 页宿主"真卸载"判断改成「代次 + 微任务」

- **发现方式**:修 1 的真机复现里出现 `⚠️ 连着两步都没成(最后一次:指定的内嵌页已经不在了(webContents 5482 已关闭或不是内嵌页))`
  —— AI 正在驾驶的页被销毁了。顺线读到 `BrowserPanel` 的宿主生命周期。
- **根因**:`panelUnmountedRef` 是**一次性布尔标志**,cleanup 只把它设 `true`、**从不设回 false**;
  而 `useRef(false)` 的初值只在**新实例**上生效 —— `apps/desktop/src/main.tsx:72` 里 `<StrictMode>` 是开着的,
  开发模式下 React 会在**同一个实例**上跑一遍「setup → cleanup → setup」
  ⇒ 标志从挂载起就**永远是 true** ⇒ 宿主效果**每一次依赖变化**(开页/关页/drivingIds 变)
  都把**当前所有**原生视图销毁重建 ⇒ 驾驶目标当场作废、页被重建。
- **改法**:不再用跨渲染的标志。改成**代次 + 微任务**:cleanup 把销毁推迟一个微任务,并检查
  「有没有更晚的挂载」—— StrictMode 的**假卸载**被紧随其后的重挂取消(不抖动),**真卸载**才执行。
  宿主效果里**故意不留 cleanup**(依赖变化绝不能销毁视图)。
- **验收**:新增 ⑥-2(关光页→重开→allTabs 再变不得销毁)与 ⑰(StrictMode 下:假卸载不销毁 /
  依赖变化不销毁 / 真卸载必须销毁);反证 C7(宿主效果加回 cleanup)、C8(摘掉假卸载判断)**都变红**。
  另外:修 1 的 effect 让旧 C2 注入不再算缺陷,故把 C2 加强成「启用按钮整体失效」。

### 修 3 · create 回执晚于关页 ⇒ 孤儿原生视图

- **根因**:`browserViewCreate` 是异步 IPC,而「关页」可能赶在它回执之前
  (开页后立刻点 ✕ / 登出时 `closeAllTabs` 紧跟开页 / 深休眠)。那种时序下 `hostGone` **先到**:
  `viewHostClose` 在 `entries` 里找不到这条 tabKey(视图还没建)是**空操作**;随后 create 回执才落地
  ⇒ 原生视图照样建出来挂在窗口上 ⇒ **孤儿视图**(页在后台继续跑、渲染进程与内存收不回来,直到窗口关闭)。
- **改法**:`hostMounted` 回执落地时**先确认这张页还在**(`findTab` 读权威 `pagesRef`),
  不在就当场 `browserViewClose` 掉。
- **验收**:新增 ⑱(用桥桩把 create 回执延迟 90ms 构造竞态);反证 C9 → **变红**。

## 六、自动化测不出的主观项(需要你亲自看一眼)

自动化能证明「列可见、页已加载、几何正确」,证明不了**体感**。请打开应用后凭直觉判断这几条:

1. **列弹出来的时机与动画**:说「打开抖音」后,右侧列是**滑入**的(240ms transition)。
   这个时机是"正好"还是"抢视线"?——特别在你正在读聊天时。
2. **AI 自己开页会不会打扰你**:`openFromPage`(页里点 `target=_blank` / AI 自己开新页)**故意不弹列**。
   实际用起来,你会不会觉得"它开了页我却看不见"?还是"它安静干活正好"?
3. **「💬 对话」按钮的语义**:点它是"收起浏览器(任务照跑)"。收起来之后右下角那个小图标够不够显眼?
4. **多 tab 时的顶栏**:截图里 4 个 tab 已经挤到要截断("Examr"),你看着顺不顺眼?
5. **真机上页与占位区是否严丝合缝**:拖窗口边缘/缩放时,页会不会慢半拍或漂移?(沙箱里量不到"跟手感")

## 七、剩余风险与已知缺口

1. **聊天里说「打开 XX」在"有循环正在跑"时不会开页**:`useChat` 在 `runningLoopId && streaming` 时
   把消息当作**补充指令**发给正在跑的循环(第 21 步的既有设计)。实测:「打开百度」被当成
   `💬 用户补充指令` 追加进循环,没有开百度。**是否算缺陷取决于产品意图**——见建议清单 B-1。
2. **「停」在没有循环跑的时候会继续走后面的派活流程**(`useChat` 第 500 行的 `if` 后面没有 `return`)
   ⇒ 可能用目标「停」起一个循环。见建议清单 B-2。
3. **同名下载会静默覆盖**:`item.setSavePath(项目下载目录/原名)` —— Electron 语义是同名覆盖,
   没有"自动改名"或提示。见建议清单 B-3。
4. **tab id 用 `Date.now()+random(1000)`**:同一毫秒内两次开页有 1/1000 概率撞 id(React key 冲突 +
   宿主 map 冲突)。见建议清单 B-4。
5. **孤儿视图的"另一半"仍在主进程**:修 3 在渲染层收口(回执落地时确认页还在)。
   若将来有别的调用方绕过 `hostMounted` 直接 create,主进程侧没有 tombstone 兜底。
6. **下载归属在 `fromWc` 缺失时会回落到"该 session 的第一张页"**(`ownerAgentOf((fromWc ?? contents).id)`)
   ⇒ 极端情况下 agentId 可能记错(注释里已记录这个坑)。
7. **真机渲染/跟手感/多显示器 DPI**:本报告只覆盖本机单显示器 100% 缩放。
