## 片 1 · `features/knowledge`（资料/知识库）

**为什么先抽它**：依赖最少、边界最清（一段完整的 I/O + 5 个状态 + 1 个 DOM ref），
用来把"抽一片"的整套做法跑通，风险最低。

### 改了什么

| 文件 | 动作 |
|---|---|
| `apps/desktop/src/shared/api.ts` | **新增**：把 `API_BASE` / `TOKEN_KEY` / `authFetchJson` / `dbHint` 从 `App.tsx` 的模块级**原样搬出**（连注释一起）。理由：这 4 个被 30 多处逻辑用到，抽 feature 时它们必须离开 App.tsx，否则每个 feature 都要**反向依赖 App** |
| `apps/desktop/src/features/knowledge/useKnowledge.ts` | **新增**：`loadKnowledge` / `uploadKnowledgeFile` / `onChooseKnowledgeFile` / `deleteKnowledgeDoc` + 5 个状态 + `fileRef`，**逻辑逐字未改**（含 4 条守卫：切号晚到响应、扩展名白名单、12 MB 上限、DELETE 送 `{}`） |
| `apps/desktop/src/features/knowledge/index.ts` | **新增**：该 feature 的**唯一公开 API**（feature 之间只许从这里 import） |
| `apps/desktop/src/App.tsx` | 删掉搬走的 4 段逻辑 + 6 行 state/ref 声明 + 4 个不再使用的类型 import；改为一行 `useKnowledge({ sessionRef, curProjectRef })` 并用**同名解构**接回 |

**关键手法：只换来源，不改名字。** 解构出来仍叫 `knowledgeDocs` / `loadKnowledge` / …，
所以 App.tsx 里 35615 字符的 JSX **一个字都不用改**：

```
★ JSX 段（从 `return (\n    <div className="app">` 到文件尾）逐字节一致：True
  App.tsx 3714 行 → 3595 行（净 −119）
```

### 守住的两条（用户点名）

1. **13 个 ref 里 7 个"最新值镜像"一个都没删** —— 本片把 `sessionRef` / `curProjectRef`
   **注入**进 hook（hook 自己不持有会话与项目的真相），而不是在 hook 里另建一份。
   顺带确立分层方向：`features/**` 可以依赖 `shared/**`，**不许反向依赖 `app/**`**。
2. **`browser/` 一行没动**（本片根本没碰它）。

行为网的 8 条（挂**整个 `<App/>`**、点**真实按钮**、断言**真实 DOM 与真实 fetch 路径**）：

1. 启动后按当前项目拉过一次资料列表（真实请求 `/knowledge?projectId=7`，GET）
2. 入口显示服务端条数（`知识库（2）`）
3. 点开后列出两条资料，文件名与删除按钮都在
4. `.exe` 被挡下并给出人话提示，**且没有真的发上传请求**
5. 超过 12 MB 被挡下
6. 删一条：走 `DELETE /knowledge/11`、列表**立刻**少一条、回一句人话、**body 必须是 `'{}'`**
7. 登出把这套状态清干净（`reset()` 收掉原先散在 `onLogout` 里的 5 行）
8. 切号守卫：A 号的慢响应晚到时**不许覆盖** B 号列表（在**真实 hook** 上验，不是副本）

### 反证

`scripts/verify/app-logic-smoke-revert.py` —— 往**抽出去的 feature 源码**里注入 4 种
"搬代码时最容易犯的错"：**4/4 全部咬住**，每次还原后 md5 逐字节一致。

| # | 注入 | 命中 |
|---|---|---|
| K1 | `load` 里删掉「切号后晚到的响应不许覆盖列表」 | A 号请求晚到时不许覆盖 B 号列表 |
| K2 | 扩展名白名单放宽（放进 `.exe`） | 不支持的扩展名被挡下 |
| K3 | `remove` 不再本地过滤（改成等服务端重拉） | DELETE /knowledge/11 那一条 |
| K4 | DELETE 不送 body（Fastify 会判 400 的老坑） | 「DELETE 的 body 必须是 '{}'」 |

> 为什么往 feature 里注入、而不是往 App.tsx 里：这一片的价值就是**"搬出去之后行为一字未变"**，
> 最该被证明的是 feature 内部那几条守卫还在。
